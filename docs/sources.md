# Source intake and conversion

## Available scope

Sources retain attempts, access state, original/canonical URLs, raw-byte digests, snapshots and
explicit limitations. GitHub material is pinned to a commit and verified blob/tree identity.
Public YouTube/X/TradingView readers are limited; metadata or a visible page does not establish
access to transcripts, media or Pine source. Instagram acquisition is incomplete.

Use `/source` for supported URLs, `/source-text` or `/source-file` for supplied UTF-8 material,
and `/source-captions` for explicit WebVTT/SRT files. Supplied attribution is not provider acquisition
or verified publication identity. See `/help` for exact arguments.

Acquisition does not register, approve, backtest or activate a strategy. Do not follow repository
symlinks/submodules, import acquired code, execute widgets or open provider-returned links.
Source credentials remain in memory and scoped to their intended API host.

## Reviews

A source review binds an exact registered strategy and retained snapshot. The model selects
application-owned passage indices; the application constructs literal quotes and coordinates.
Preserve every readable character, exact final spans and immutable versioned receipts. Reject
unknown references, metadata-only behavioral claims and cross-strategy history access.

A valid citation does not establish semantic correctness, strategy derivation or faithful conversion.
Capture time, publication claims and review time remain distinct.

## Captions

Retain raw bytes, exact payload/metadata spans, original cue order and enclosing file-local bounds.
Report quality issues without sorting or deduplicating. Malformed caption files do not fall back
to untimed text. Cue intervals are not word-level timing or a verified media clock. Canceled parser
workers cannot publish late results.

## Registration and conversion

`/source-register` is an explicit user operation for one complete supported native `strategy/1`
JSON definition. Registration atomically binds acquisition/snapshot, full behavior, identity,
stable agent, provenance, declared acyclic lineage and an immutable receipt. Duplicate delivery
cannot add another submission. Registration grants no test or execution authority.

Pine diagnostics map supported rule shapes and retain gaps; they do not prove arithmetic/runtime
conformance or enable arbitrary converted execution. Unsupported exits, timing, repainting,
parameters or missing logic block a faithful-conversion claim. `/new` cannot bypass the format gate.
Broader conversion remains future work in [the plan](../plan.md).
